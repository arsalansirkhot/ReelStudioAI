# Reel Studio AI

A Windows app for editing Kokni and Hindi Reels: remove pauses, remove repeats, add subtitles and a title. Everything runs on your own computer; your videos are never uploaded.

## What you need
- Windows 10 or 11
- Python 3.11 (64-bit) from https://www.python.org/downloads/ (tick **Add Python to PATH** during setup)
- An NVIDIA graphics card is recommended; without one, transcription is much slower

## Install
1. On this page, click the green **Code** button, then **Download ZIP**.
2. Unzip it to a simple folder, for example `C:\ReelStudioAI`.
3. Double-click `run_windows.bat`. If Windows shows "Windows protected your PC", click **More info**, then **Run anyway**.
4. The first start installs everything and can take 10 to 20 minutes. The app then opens in your browser.

## Updates
Every time you start the app with `run_windows.bat`, it downloads the latest version automatically. Your projects and videos are never touched.
